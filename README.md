# 📊 Employee Demographics & Attrition Dashboard

An end-to-end HR Analytics report built in Power BI to monitor workforce distribution, salary allocation, recruitment channels, and employee satisfaction.

![Employee Dashboard](Screenshot 2026-11-01 145820.png)

## 📌 Executive Summary
* **Total Employees:** 311
* **Active Status:** 66.56% (207 active employees)
* **Attrition / Terminated:** 33.44% (104 terminations)
* **Total Payroll:** $21M across 6 operational departments

## 🔑 Key Insights & Structure
* **Department Cost Allocation:** Production leads total salary expenditure ($13M), followed by IT/IS ($5M) and Sales ($2M).
* **Recruitment Funnel:** Indeed (87) and LinkedIn (76) represent the highest-volume talent acquisition pipelines.
* **Workforce Demographics:** Gender breakdown stands at 56.59% Female and 43.41% Male.

## 🛠️ Tools Used
* Power BI Desktop
* DAX (Data Analysis Expressions)
* Data Modeling & Power Query
